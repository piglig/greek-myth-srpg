# 希腊神话战棋（暂定名）设计文档

> 状态：概念设计阶段
> 最后更新：2026-11-19

**后续章节制作入口**：[第一章定稿美术与动画复用指南](27-chapter-art-production.md)。全游戏的视觉方向与章节色彩见[主美设定](26-art-bible.md)。

## 一句话概述

宙斯宣告终结"铁之种族"，一名凡人在天火降临前，踏遍希腊神话世界，从怪物、英雄与泰坦身上夺取力量，最终登上奥林匹斯挑战宙斯。这是一款买断制、线性章节的战棋游戏，画面采用实时三维地形、轻像素手绘材质与原画二维角色。

## 产品定位

| 项目 | 决定 |
|---|---|
| 类型 | 回合制战棋（SRPG） |
| 商业模式 | 买断制单机（PC / Steam），**不做抽卡，不卖角色** |
| 流程结构 | 线性章节，共 8 章，队伍和成长永久保留 |
| 队伍规模 | 9 名可用角色（主角 + 8 名同伴），每场出战最多 4 人，主角必须上场 |
| 核心体验 | 不断解锁能力，面对更强大的敌人；新能力带来新解法（锁与钥匙） |
| 视觉 | 实时三维地形 + 轻像素手绘材质 + 原画二维动作帧 |
